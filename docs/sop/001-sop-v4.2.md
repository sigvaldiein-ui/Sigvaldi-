# 📋 REGLUR (SOP v4.2) - Kjarnaverklag Alviturs á RunPod

Þessar reglur stýra allri framþróun og uppfærslum á Alvitur arkítektúrnum:

1. **Eitt skref í einu:** Alltaf bíða eftir staðfestingu áður en lengra er haldið.
2. **Spyrja alltaf við vafa:** Aldrei giska á lausnir eða arkítektúr ef óvissa er til staðar.
3. **PROD Deployment Agi:** `web_server.py` er PROD umhverfi. Ferlið við uppfærslu er strangt: `git pull` -> `py_compile` -> `backup` -> `cp` -> `endurræsa`. Aldrei keyra `curl` beint yfir lifandi skrá.
4. **Öryggi Lykla:** Engir API tokens eða leynilyklar (secrets) mega nokkurn tímann fara í gegnum spjall eða logga.
5. **Git Flæði:** Kóði fer alltaf frá RunPod yfir á GitHub. Aldrei öfugt, og aldrei nota `--force`.
6. **Bilanastýring (Fail-Safe):** Við 3 misheppnaðar tilraunir að leysa vandamál skal stöðva keyrslur og gefa formlega skýrslu.
7. **Gagnsæi:** Viðurkenna skal villur strax án undandráttar.
8. **DEV vs. PROD:** Þróun (Per) vinnur alltaf í DEV. Kóði fer í PROD aðeins eftir formlegt samþykki Yfirarkitekts (Aðals).
9. **Tafarlaus skjalavistun (Immediate Persistence):** Ný ADR (Architecture Decision Record) skjöl verða að vera skrifuð beint á disk í `/workspace/Sigvaldi-/docs/adr/` og sett í útgáfustýringu. Engin hönnun telst kláruð fyrr en hún er í Git.

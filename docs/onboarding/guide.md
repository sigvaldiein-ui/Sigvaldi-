# Alvitur.is: Onboarding Guide fyrir Beta-Viðskiptavini

## 1. Tenant Provisioning
- Fyrirtæki þitt fær úthlutað sérstöku `org_id`.
- Auðkenni (OIDC) tenging verður virkjuð fyrir ykkar notendur.

## 2. Admin Setup
- Admin-notandi hefur aðgang að "Samþykktarborði" (Approval Inbox).
- Allir notendur með "Starfsmanns"-hlutverk þurfa samþykki fyrir útflutningi gagna.

## 3. Support & Feedback
- Neyðarlína fyrir kerfisbilanir: support@alvitur.is
- Feedback-rás: Linear / Slack.

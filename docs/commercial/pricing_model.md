# Commercial Packaging: Alvitur.is Pricing Framework (Beta)

## 1. Billing Models
- Per-Seat: Aðgangur fyrir notendur (User-based).
- Per-Token: Notkunarmiðað gjald (LLM-Cost pass-through).
- Per-Org: Mánaðarlegt lágmarksgjald fyrir tenant-einangrun.

## 2. SLA Tiers
- Tier 1: Support á virkum dögum (8-16).
- Tier 2: 24/7 Support (Critical).
- Uptime SLA: 99.9% uptime trygging.

## 3. Compliance Docs (DPA/MSA)
- Vinnslusamningur (DPA) staðlaður.
- Áskilinn réttur til úttektar (Audit Rights).

# SOVEREIGNTY AUDIT — Alvitur.is


## Web Search Layer — Mojeek (UK)

| Atriði | Staða |
|--------|-------|
| Provider | Mojeek Ltd, Cambridge UK |
| Contracting entity | Direct (no sub-processors) |
| Tech stack ownership | 100% owned and operated by Mojeek |
| Infrastructure | UK-only data centers |
| Energy | 100% renewable since 2013 |
| Jurisdiction | UK adequacy decision (GDPR-equivalent) |
| DPA | Custom DPA negotiated 2026 (Q2) |

**Sovereignty posture:** Single point of trust, no third-party data routing, EU-adequate jurisdiction, ESG-aligned.

### Compliance landscape — Mojeek vs other search APIs

| Provider | Sub-processors | Hosting |
|---|---|---|
| **Mojeek** | **0** | UK only |
| Google Search API | 5-15+ (Alphabet entities, partner indexers, CDN, telemetry) | Global |
| Bing Search API | 8-12 (Microsoft Azure regions, telemetry, partners) | Global |
| Brave Search API | 3-5 (Cloudflare, AWS, telemetry) | US-based |

**Mojeek's "0 sub-processors" er empirically unique.** Þetta er simpler DPA (engin sub-processor list), easier audit trail (engin third-party chain), stronger sovereignty pitch (ein lögsaga, ekki margar).

### ESG angle fyrir B2G

> *"100% renewable energy since 2013"*

- EU Green Public Procurement (GPP) criteria
- Iceland's "Græn innkaupastefna" (green procurement policy)
- ESG reporting requirements fyrir banka og lífeyrissjóðir
- Future EU Sustainability Reporting Directive (CSRD) compliance
